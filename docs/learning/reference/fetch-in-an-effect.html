Fetch in an effect

Cheat sheet · from Lesson 1 · source: react.dev

The pattern

const [serverReply, setServerReply] = useState<{ id: string; data: T }>()

useEffect(() => {
  let stale = false                       // one per effect run
  void load(id).then((data) => !stale && setServerReply({ id, data }))
  return () => { stale = true }           // runs before the next run, and on unmount
}, [id])

const data = serverReply?.id === id ? serverReply.data : undefined   // undefined = loading

Rules

  • An effect can't be async: it must return its cleanup, not a promise. Use void promise.then(…) or an inner async function.
  • Cleanup runs before the effect runs again, and once on unmount.
  • In development, Strict Mode runs every effect twice, so you'll see two requests. The flag makes the first one harmless.
  • Alternative: cancel the request with an AbortController instead of ignoring its reply.
