Which body wins?

FEAT-002 Ticket 3 · Checkpoint 1 · final pass · client/src/pages/NotePage.tsx

The win: for any situation, you can say what shownBody is and what the page renders. This is the last line of CP1 you haven't been tested on. After this you've covered every line.

Step 1The two lines

const serverBody = serverReply && serverReply.id === noteIdFromUrl ? serverReply.body : undefined   // Lesson 1
const shownBody = (noteIdFromUrl && localBodies[noteIdFromUrl]) ?? serverBody
...
if (shownBody === undefined) return null

localBodies comes from useNotes(). It's your local copy: whatever you typed on this device, kept in localStorage by note id until autosave arrives in Ticket 4. If you've never typed in this note here, localBodies[noteIdFromUrl] is undefined.

Step 2?? is not ||

a ?? b gives b only when a is null or undefined (MDN). a || b gives b whenever a is falsy, and that includes the empty string ''.

Tiny example

You delete every word in note B. Your local copy is now ''. The server still has 'Cells'.
'' ?? 'Cells' → ''. Your empty note stays empty. ✓
'' || 'Cells' → 'Cells'. The text you deleted comes back. ✗

Why render nothing instead of an empty box while loading? If you could type into an empty box, your typing would become the local copy. Then, by row 1, the local copy wins, and the server's body would never show.
